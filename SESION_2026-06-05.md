**Commit:** `51fef6a`

**Archivos creados/modificados:**
- `app/(dashboard)/rutas/page.tsx` — Server Component, query supervisores + paradas por semana

**Diseño:** Cada celda muestra **chips** con el nombre del proyecto visitado (no solo un número). Navegar semanas con ← Anterior / Siguiente →. Botón "Ver ruta" o "Crear ruta" por supervisor.

### 4. FASE B — Asignación Supervisor ↔ Proyecto ✅
**Commit:** `0e10255`

**Problema resuelto:** No existía relación formal "supervisor responsable de proyecto". Solo había links implícitos via AsignacionPersonal.

**Schema change:** Nuevo modelo `AsignacionSupervisor`:
```prisma
model AsignacionSupervisor {
  id           String     @id @default(cuid())
  supervisorId String
  supervisor   Supervisor @relation(...)
  proyectoId   String
  proyecto     Proyecto   @relation(...)
  desde        DateTime   @default(now())
  hasta        DateTime?  // null = asignación activa
  creadoEn     DateTime   @default(now())
}
```
`npx prisma db push` ejecutado — tabla creada en Supabase.
`npx prisma generate` ejecutado — cliente regenerado.

**Archivos creados:**
- `lib/actions/asignacionSupervisor.ts` — `asignarSupervisor()` + `desasignarSupervisor()`
- `app/(dashboard)/rutas/asignacion/page.tsx` — nueva página
- `components/rutas/AsignacionBoard.tsx` — tabla proyectos con supervisor actual + historial expandible
- `components/rutas/CambiarSupervisorDialog.tsx` — Dialog shadcn, 2 clicks para cambiar

**Sidebar:** Nueva entrada "Asig. Supervisores" con ícono `ClipboardList` bajo PLANIFICACIÓN.

**Flujo:** Ir a `/rutas/asignacion` → ver todos los proyectos activos → click [Cambiar] → elegir supervisor → guardar. El historial de rotaciones queda registrado con fechas.

## Decisiones de arquitectura tomadas hoy

### Visitas vs Asignaciones (separación de conceptos)
- **`ParadaRuta`** = visita semanal efímera (cualquier supervisor puede cubrir cualquier proyecto)
- **`AsignacionSupervisor`** = responsabilidad formal y permanente (con historial de rotaciones)
- Estas dos entidades son independientes — cambiar una no afecta la otra

### DnD preparado pero no activado
El panel `/rutas` está arquitectado para drag & drop futuro:
- `Chip` → se convierte en `useDraggable()`
- `CeldaDia` → se convierte en `useDroppable()`
- Instalar `@dnd-kit/core @dnd-kit/sortable` y envolver los componentes

### Vista doble en Dotación
- Vista tabla = operaciones completas (editar, evaluar, desvincular)
- Vista tablero = solo mover rápido entre proyectos
- Toggle con íconos Lucide, persiste en estado local (no localStorage por ahora)
